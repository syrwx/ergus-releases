# Ergus — installeurs

Ce dépôt ne contient **aucun code**. Il sert uniquement à distribuer les
installeurs d'Ergus et à permettre aux copies déjà installées de se mettre à
jour toutes seules.

## Télécharger

**[→ Dernière version](https://github.com/syrwx/ergus-releases/releases/latest)**

Prenez le fichier `Ergus-x.y.z-installeur.exe` et double-cliquez dessus.

Windows affichera *« Windows a protégé votre ordinateur »* : l'installeur n'est
pas signé par un certificat payant. **Informations complémentaires** →
**Exécuter quand même**.

## Ergus, en deux lignes

Une couche d'intelligence artificielle qui se pose sur une installation de
vidéosurveillance existante. Elle ne remplace pas l'enregistreur : elle analyse
les flux **en local**, et hiérarchise ce qui se passe par un score de risque.

Aucune image ne quitte la machine.

## Mises à jour

Une fois installé, Ergus regarde ici toutes les six heures. Quand une nouvelle
version paraît, il la télécharge et propose de redémarrer — jamais de lui-même.
